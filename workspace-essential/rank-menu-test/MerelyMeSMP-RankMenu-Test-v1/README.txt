MerelyMeSMP Visual Test v2

Client test pack for Minecraft 1.21.11 Fabric + OptiGUI.
Based on MerelyMeSMP-Menu-Ranks-BanHammer-v5.1-Fixed.
The BanHammer assets are preserved.

The blue GUI is limited by inventory title to Crates (including AFK), Stats, Rank Permissions, Help, Shop, Playtime, 1v1, 2v2, Tournaments, Kits, Media, Rules, Battle Pass, Update and Daily Wheel. Only the upper server-menu section is blue; the player inventory and hotbar retain the vanilla Minecraft texture. Other chest menus remain vanilla.

Cosmetic samples (paper CustomModelData):
9000 Angel Wings; 9002 BlueFire Wings; 9011 Phoenix Wings
10000 Diving Helmet; 10003 Military Helmet; 10005 Pot Hat
11000 Common Crate; 11001 Legendary Crate

12000 Animated Earth source (static item preview)

The crate samples are static item previews. Their Blockbench animations need a server model/cosmetics plugin for playback.
