MerelyMeSMP Local Client Pack

Minecraft: 1.21.11 Fabric

Includes:
- Clean rank glyphs using the official Minecraft font style.
- Graphite and silver menu theme inspired by the supplied reference.
- Theme applies only to server/plugin chest menus whose titles match Auction House, Help, Sell, Shop, Point Shop, Crates, Claim, Tags, Glory, Tournament and related menus.
- Vanilla Inventory, Chest, Ender Chest, Crafting Table, Shulker Box and other normal containers remain unchanged.

Client requirements:
- Fabric API
- Fabric Language Kotlin
- OptiGUI

This is a local client-only visual test. It changes no server files.
